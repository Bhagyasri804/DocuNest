# DocuNest

Smart Document Management and Collaboration System.

## Overview
DocuNest is a full-stack platform for securely
storing, organizing, sharing and managing documents.

## Technology Stack
- Frontend: React.js and Vite
- Backend: Node.js and Express.js
- Database: MySQL
- Authentication: JWT
- Version Control: Git and GitHub

## Main Modules
1. Authentication
2. User Management
3. Document Management
4. Folder Management
5. Document Sharing
6. Version Control
7. Approval Workflows
8. Notifications
9. Audit Logs
10. Analytics Dashboard
